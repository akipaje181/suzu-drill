# すずドリル

2年生 文しょうだいの自動まるつけアプリ（PWA）。
公開URL: https://akipaje181.github.io/suzu-drill/

iPadのSafariで開き「ホーム画面に追加」で使います。ログイン不要・オフライン可。

## 画面
- ホームの入口: 上の**部屋の絵カード（見出し「🏠 マイルーム」／右に「ひらく →」）**をタップ、またはタイルの**「マイルーム」**からマイルームへ。「きょうの クエスト」の下の「おうちの人へ：クエストを えらぶ・ふやす（マイルーム）→」は、クエスト設定（`#qsec`）へ直接ジャンプする（v18）。
- ホーム → きょうの 5問（8単元・34型の生成器から毎回ちがう問題）／テストの プリント（1-⑤〜1-⑦ 各10まい）／にがてを とく／せんせいの ワンポイント（34講座）／きろく／いんさつ（型から作る・PDF）
- 各問題に手書きエリア：（しき）・こたえ の罫線＋（ひっさん・図）の方眼。ペン／けしゴム／太さ3段階。太さボタンは選択中の道具に効き、ペンとけしゴムで別々に記憶（localStorage: suzu.pen.size / suzu.eraser.size）。Apple Pencil＝書く／指＝スクロール（枠ごとの「指で かく」で指書きに切替）。Pencil使用中は手のひら・2本目の指を無視

## ファイル
- `index.html` アプリ本体（**これが元データ**。問題データ・講座文も中に入っている）
- `sw.js` オフライン用キャッシュ
- `manifest.webmanifest` / `icon-*.png` ホーム画面用
- `pdf/<テスト>/{problems,answers,points,all}.pdf` 印刷用PDF（`../文しょうだい再テスト/` と同じもの）

## 更新のしかた
1. `index.html` を直す（テストの固定問題は `var DATA`、型は `var TYPES`／`var UNITS`、講座は `var LESSONS`、生成器は `GEN.<型>`）
2. **`sw.js` の `VERSION` を上げる**（例: v2 → v3）。上げないと端末側が古いキャッシュを使い続けることがある
3. `git commit` → `git push origin main` で自動公開（数十秒〜数分）

## 学校（湘南白百合学園小学校）の教材に合わせる（v19）
親が送った教材写真（1年のもの。学年は上がっても同じシリーズ）から読み取った学校の教材構成:

| 科目 | 教材 | アプリへの反映 |
|---|---|---|
| 国語 | 光村図書「こくご」 | 漢字の出る順は光村＝学校のかんじドリルの順。→「学校で ならった 字だけ 出す」で進度に合わせる |
| 算数 | 東京書籍「新編 あたらしい さんすう」 | 単元を東京書籍の順（1〜3学期）に並べ、「学校は いま ここ」から手前だけ出す |
| 漢字 | 青葉出版「新 くりかえし かんじドリル」（光村準拠・書き始めと向きの▶マーク入り） | 上と同じ。筆順の矢印表示は未対応（次の課題） |
| 計算 | 四谷大塚「一歩先を行く リーダードリル 算数 計算」（予習シリーズ・1回1枚・全60回・先取り） | **「けいさん 1まい」＝全60回・1回10問**のコースを新設 |
| 発展 | 奨学社「段階別 最レベ さんすう問題集」（難関中学志向） | **「ちょうせん（はってん）」単元 6型**を新設 |

読み取れる方針: ①教科書の進度に沿った標準 ②毎日1枚の計算 ③発展（中学入試の基礎）の3層。アプリもこの3層に合わせた。

### けいさん 1まい（全60回）
- ホームのタイル「けいさん 1まい」。1回=10問、**同じ回は同じ問題**（`rng(kai*7919+13)`）なので、間違えた回をやり直すと確かめになる。
- 回の進み方（`COURSE`）: 1-8 2けたのたしひき／9-14 3つの数／15-20 100より大きい数／21-26 九九(2･3･4･5)／27-32 九九(6･7･8･9･1)／33-38 九九ぜんぶ・○ばい／39-44 3けたのひっさん／45-50 □をもとめる(先どり)／51-56 長さ・かさ／57-60 まとめ。
- 生成器は `CGEN`（`c_*` キー。34型の記録とは混ざらない）。手書きは 200px の方眼（`pad:'calc'`）、式は 30px。
- 進捗は `_game.keisan = {done:{回:点}, at:つぎの回}`。1枚=1セットとして目標・クエストにも数える（`isSetLog` に `keisan` を追加、ポイントは漢字と同じ 答えた+1/正解+2）。

### ちょうせん（はってん・最レベ風）
`UNITS` に `chosen` を追加（型は `CHOSEN_TYPES`、生成器は `GEN.*`、講座も `LESSONS` に追加済み。印刷「型から 作る」にも出る）:
和差算（あわせて と ちがい）／かさねてつなぐ長さ／同じ数ずつ分ける（わり算の芽）／うしろからなんばんめ／休みをはさんだ時こく／1つ分をもとめる。すべて2年の既習（九九・半分・図）で解ける形にしてある。

### 学校の じゅんばん
- `SCHOOL`（東京書籍めやす）: 1学期 ならび方→たし算とひき算→長さ→お金と数／2学期 かさ→時こくと時間→かけ算／3学期 図をつかって／いつでも ちょうせん。
- マイルーム →「学校の しんど」で「学校は いま ここ」を設定（`_game.unitNow`）。設定すると「きょうの 5問」に**「ならった ところから 5問」**が出る（`learnedKeys()` = そこまでの型すべて）。単元タブも学期見出し付きで教科書順に並ぶ。

### 学校で ならった 漢字
- かんじ画面に「学校で ならった 字」パネル。10字を1字ずつタップ、または「この グループ 10字に 印を つける」。`_game.learned`。
- 「ならった 字だけ 出す：する」（`_game.onlyLearned`）で、よみ・かき・なぞり・かきとりを印のある字だけから出す（そのグループに4字未満なら、印のある字ぜんぶから出す）。
- **次の課題**: 青葉出版のかんじドリルの目次（教材名と漢字の並び）を写真でもらえば、160字を光村の出る順に並べ替え、教材名（「ふきのとう」等）でグループ分けできる。

## かんじ（小2 配当160字）
- データ `var KANJI`: 16グループ×10字（テーマ別）。各字に よみ（音／訓）と ことば2つ＋例文。生成元は `tools_kanji_data.py`（`python3 tools_kanji_data.py` で検証：160字と配当表の一致、例文中に語が1回。直したら index.html の `var KANJI` を差し替える）。
- 練習4種: よみ4択／かき4択（漢字ノート枠に書いてから選ぶ）／なぞり書き（うすい手本を2ます＋空き2ます、「かけた！」）／かきとり（手書き→「こたえを 見る」→ ○✗ を自分でつける）。「にがてな 漢字」は間違いの多い字から よみ／かき をランダム出題。
- 記録は `_types['k_<字>']`。おぼえた＝3回以上正解かつ正答率8割。きろく画面にグループ別の一覧。
- 手書き枠は `makePad(key, 'kanji', model)`：4つの十字ます、手本は `.model.trace`／`.faint`。字体は Klee One（教科書体風、Google Fonts）。
- 印刷「かんじ ノート」: 1グループ=A4 1枚（手本＋よみ・ことば＋なぞり1ます＋空き3ます）。`?gen=kanji:g3` または `?gen=kanji:all` でPDF化。
- ポイントは1問あたり 答えた+1／正解+2（10問なので算数の5問と同程度）。1セッション＝1まい として目標にも数える。

## テストの写真の取り込み（かんたん版：APIキー不要）
1. iPad「テストを よみとる」→ 撮る → 名前を黒塗り → **おくる** → 共有シートで「ファイルに保存」
   → `iCloud Drive › すずドリル › テストの写真`（AirDrop で Mac に送ってもよい）
2. Mac 側の同じフォルダ: `~/Library/Mobile Documents/com~apple~CloudDocs/すずドリル/テストの写真/`
   Claude Code に「テストの写真を入れた」と伝える → Claude が写真を読んで型と○✗を判定
3. `python3 tools_add_page.py "9/12 小テスト 1-⑧" dochira:x aida:o sorezore:x ... --push`
   → `index.html` の `var PAGES_PRESET` にページが追加され、sw.js の版が上がり、push される
4. iPad は次にアプリを開いたとき（ネット接続時）にページを取り込み、○✗を記録に反映、トーストで通知
   （`applyPresetPages`。削除したページは `_pagesDeleted` に記録され再取り込みしない）
読み終えた写真は `よみとり済み` フォルダへ移す。

## テストの読み取り（AI）
- ホームの「テストを よみとる」：写真 → 名前を黒塗り → Claude で型・○✗を読み取り → 確認 → その子用の10まいページ。
- ブラウザから直接 Anthropic API を呼ぶ（`@anthropic-ai/sdk@0.124.0` を jsDelivr の ESM で読み込み、`dangerouslyAllowBrowser`）。
  APIキーは端末の `localStorage`（`suzu.apikey`）にだけ保存。サーバは無い。
- モデル `claude-opus-5`、画像は長辺2000pxのJPEG、`output_config.format` の JSONスキーマで構造化出力。
  安全分類器の拒否に備えて `fallbacks: "default"`（beta `server-side-fallback-2026-07-01`）を付け、400なら通常エンドポイントで再試行。
- 読み取り結果は「型・要約・数・正答・本人の答え・○✗・自信」。問題文の原文は保存しない（要約のみ）。
- 作ったページは `recs._pages`（seed付き）。プリント10まいは生成器から seed で再現。○✗は型別の記録に即反映。
- 費用の目安: 1枚 ¥15〜40（利用者のAPIアカウントに課金）。

## もんだいの むずかしさ（型ごとに 自動で 上がる・v21）
「レベルのスピード」とは切り離し、**難易度はその型の成績だけで決まる**。動機づけ（ポイント）と学力（難しさ）を別のダイヤルにする方針。

- `typeLv(key)`: その型の記録から 0/1/2 を返す。**5回以上で8割正解 → Lv.2、12回以上で9割 → Lv.3**（表示は +1。Lv.2＝「マスター」メダルと同じ条件）。
- `makeProblem` が `GD` にセットして生成器を呼ぶ。生成器の中は `gd(きほん, むずかしい, もっと)` で数の範囲や選択肢を切り替える（40型すべて対応）。にがてな型は Lv.1（今までと同じ）のままで、**難しくならない**。
- 上がり方の例: あわせて 2けた→3けた（352+305）／のこり 662-384／おつり 50円→1000円で751円／時こく 80分後（2時間くり上がり）／長さ・かさは くり下がりを必ず入れる／かけ算は九九→×12（先取り）／100より大きい数は1000円さつを追加／ちょうせんは数を大きく。
- ポイント: 正解1問につき `XP.hard(=2) × (Lv-1)` を加算し、結果に「むずかしい もんだい ボーナス」として出す。Lv.3の5問なら +20（同じ5問で 40→60ポイント）。`item.gd` に持たせ、「もういちど」でも引き継ぐ。
- 見える化: まるつけ後の型名に「むずかしさ Lv.2」、きろくの型別に赤いピル、「きょうの 5問」の説明に「とくいに なった ○の 型は すこし むずかしい 数に なります」。
- 検証: `harness.js`＋`verify.js` で **40型×3段階×400問＝48,000問**を機械検証（しきの計算・ひき算が負にならない・答えと最後のしきの一致・cm/mm・L/dL・時分の範囲）。エラー0。この過程で「かさのひき算で 0L…」「mのひき算で 0m…」になる既存バグも直した。

## やる気の仕組み（ポイント・レベル・もくひょう・スタンプ・メダル・なかま・マイルーム）
- ポイント（`XP`）: 答えた問題 +2、正解 +3（にがて +4）、5/5 +10、**1まい +5**、5まいごと +20、10まいごと +50、**その日の1まいめ +10**、連続日数×5（7日まで）、講座正解 +3、テスト読み取り +20。
- もくひょう（親が「マイルーム」で設定）: 1日○まい（既定2）→ +30／週○日（既定5）→ +60／週○まい（既定10）→ +60。週は月曜始まり。
- レベル: **はじめは早く、やがて「ふつうの1日＝約1レベル」**（v20で調整）。Lv.1→2 は 100ポイント、以降 20ずつ増えて上限で一定（`LV_START=100`, `LV_STEP=20`, 上限＝スピード設定 `LV_SPEEDS`：はやい140／**ふつう180（既定）**／ゆっくり240）。しきい値は `cumTable()` にキャッシュ。
  - 実測（7日連続・あいさつ＋クエスト4つ＋親✓＋ふりかえり＝84ポイント）: 1まいの日 約160（0.9レベル）／2まいの日 279（1.55レベル）／何もしない日 0。最初の3日で Lv.5 まで上がる設計。
  - v19までの「100ポイントで1レベル」から移行するとき、**レベルが下がらないように** xp を底上げする（`game.curve2` フラグ、`initGame`）。スピードを変えたときも同じ（`setLvSpeed`）。
  - 「レベルの スピード」はマイルームで変更可（親向け。既定ふつう）。
- ドリまる: たまご(Lv1)→あかちゃん(3)→こども(7)→おとな(15)→マスター(30)→**ヒーロー(45)→でんせつ(70)**（v20で2段階追加。`charInner` は st5=二重リング、st6=星3つ）。色6色、名前、アクセサリー6種。
- **★（10レベルごとに1つ・上限なし）**: `starsOf(level)`。マイルームに大きく表示し、部屋の左壁の棚に最大6つ描画（それ以上は ×n）。レベルアップ時に「★が ○こに なった！」。
- **つぎの ごほうび表示**: `nextReward()` が段階・かざり・アクセ・なかま・★のうち一番近いレベルのものを返し、ホームのカードと結果パネルに「つぎの ごほうび：Lv.○で △」と出す（飽き防止の要）。
- なかま（`MATES`）10匹（v20で もこすけ=Lv.20、ドラごん=Lv.35 を追加）: うさまる(10まい)・ねこたろう(3日連続)・くまきち(30まい)・ペンすけ(7日連続)・かえるん(型マスター×3)・ロボまる(スタンプ30)。`charInner` の `sp` で描き分け。
- マイルーム（`roomSVG`）: 窓は時刻で昼/夕/夜、今週のカレンダー、本棚は5まいごとに1冊、机のドリまる、なかま、★の棚、かざり（`DECOR` 12種。v20で きんぎょばち18／ピアノ22／こどもテント26／ほしのモービル30 を追加。レベルやメダルで解放、置く/しまう）。
- スタンプカード: まるつけした日に1こ。30こで1枚。連続日数・最長連続を表示。
- メダル: 20種（`BADGES`）。型マスター＝その型を5回以上解いて正答率8割。
- 状態は `recs._game`（xp, name, color, wear, stamps, badges, lessonsRead, wasWeak, sound, perfects, sets, weakSets, scans, goals, bonus, mates, decor, streakMax）。初回は過去の `_log` から換算。
- 音（レベルアップ・メダル時の短い和音）は「マイルーム」でオン/オフ。

## きょうの クエスト（学校・おうちの目標で レベルアップ／毎朝ひらきたくなる仕組み・v15）
ホームのマイルームカードの下に「きょうの クエスト」カード。
- **あいさつ**（1日1回）: 「おはよう！」（11時〜「こんにちは」、17時〜「こんばんは」）を押すと +10、8時前なら はやおき +5、れんぞく日数×2（7日まで）。押すとその日の **おみくじ**（うんせい／ラッキーカラー／ラッキーアイテム／ひとこと。日付＋名前のハッシュで決まる、悪い運勢は出ない）が開く。
- **クエスト一覧**: ①ドリル（1日の目標まい数、自動）＋②学校の目標（月〜金のみ表示）＋③おうちの目標。子どもがタップで ✓（+10。押し直しで取り消せるがポイントは同日2回目以降は付かない）。✓ 済みの行に「おうちの人の ✓」（confirm付き、+10）。
- **ぜんぶ クリア** +30 → 週内のぜんぶクリア日数が「こんしゅうの おおきな もくひょう」（既定3日）に達すると **+100（＝1レベル）** と ごほうび（親が文字で設定、任意）。
- **ふりかえり**: 😄😊😐😢 を1つ選ぶと +10（1日1回）。
- 設定は「マイルーム」→「クエスト」: プリセット16種（学校8・おうち8）を出す/しまう、「じぶんで 書く」で追加（タップで削除）、おおきな もくひょうの日数とごほうび。初期値は 学校2＋おうち2（`QUEST_DEFAULT`）。
- 定数: `XP.quest/parentOk/allClear/morning/early/evening/bigGoal`、プリセット `QUEST_PRESETS`、おみくじ `LUCKS/LUCKY_COLORS/LUCKY_ITEMS/FORTUNE_LINES`。
- 追加メダル6（はじめての クエスト／ぜんぶ クリア／×7／あいさつ 7日／おおきな もくひょう／おうちの人の ✓ ×10）、なかま2（ひよぴ＝あいさつ5日連続、ふくろう＝ぜんぶクリア×5）。
- 状態: `recs._game` の `quests{on,custom}`, `qdone`, `qok`, `qpaid`, `qpick`, `morning`, `evening`, `allclear`, `big{need,reward,done}`, `pickN`, `qxp`, `allXp`, `okOn`, `schoolAll`。

### クエストの項目と 選べるしくみ（v17）
- プリセット **57種／7グループ**（`QGRPS` と `QUEST_PRESETS`）: 📗じゅぎょう9・🎒学校のせいかつ9・🤝ともだち7・🌅あさ7・🌙よる7・🧹おてつだい9・💛こころとからだ9。
  グループに `wd:1`（じゅぎょう・学校のせいかつ）があるものは 月〜金だけ出る（親が「まいにち」に変更可＝`schoolAll`）。行の下に出る小さなラベルは `QCAT`（グループの `short`）。
- **本人が その日の分を えらぶ**: 出している数が「1日に 出す かず」（`pickN`、既定4）より多いと、ホームに「きょうの クエストを えらぼう」パネル（`pickPanel`）が出て、本人がタップで選ぶ。「🎲 おまかせで きめる」で全部ランダム。まだ1つも ✓ していなければ「クエストを えらびなおす」で選び直せる。選んだ結果は `_game.qpick[日付]`。
  「ぜんぶ」（0）にすると 出しているものが全部出る（v16までと同じ）。えらぶ画面が出ている間は クエストが1つ（ドリルのみ）なので「ぜんぶクリア」は発火しない。
- **親が設定できるもの**（マイルーム →「クエスト」）: 1日に出すかず（ぜんぶ/1〜8）、1つのポイント（5〜30、5きざみ）、ぜんぶクリアのポイント（10〜100、10きざみ）、おうちの人の✓を使うか、学校のクエストを月〜金だけ/まいにち、グループごとの出す/しまう（7グループを折りたたみ表示・`qOpen`）、グループごとに「＋ じぶんで つくる」（文と えもじアイコンを prompt で入力。既存のものはタップで直す／からっぽにして OK で消す）、おおきなもくひょうの日数とごほうび。
- v16までの `custom`（`cat:'school'|'home'`）は起動時に `grp`（life/help）へ自動移行。プリセットの id は変更していないので これまでの設定は そのまま有効。
- レベル上限は 999（以前は99）。

## 立ち上げたときの 声かけ（v16）
アプリを開いた最初のホームで、ドリまるが**そのときのがんばりに合わせたポジティブな一言**を言うカードを最上部に出す。
- 出るのは1回（起動ごと）。✕ で閉じられ、他の画面へ移る（`open()`）と消える。次に開いたときまた出る。
- カードをタップすると別の一言に変わる（`welcomePool()` から再抽選。毎日開きたくなる小さな仕掛け）。
- 一言の選び方（`welcomePool`）: はじめて／4日以上ぶり＝「おかえり」／今日クエスト全クリア／今日もう解いた／連続3日以上／レベルまであと30以下／きのうの枚数／メダル3個以上、＋時間帯（朝・昼・夜の `WEL_MORNING/WEL_DAY/WEL_NIGHT`）。**できていないことは言わない**（責める言葉は入れない）。
- 下段は応援のことば `CHEER`（「まちがいは つよくなる もと」等）。
- 「はじめて」判定と「なん日ぶり」は れんしゅう・あいさつ・クエスト・ふりかえり の記録すべて（`activeDays()`）から見る。
- 幅430px以下では あいさつボタンを 横いっぱいに（小2が押しやすいように）。
